Registry


VFWCreateIfNot

setdefault = VFWCreateIfNot(type, address, default)

Arguments
type ("string", "int", "float", "bool") - The type of data stored.
address (string) - The address the data is stored at
default (any) - The default value the data will be reset to.

Return value
bool - If the default value is set.

If the Registry exists than returns false, else sets the Registry to the default value and returns true.

    if VFWCreateIfNot("int", "savegame.mod.gamescore", 0) then
        DebugPrint("Score is: "..GetInt("savegame.mod.gamescore"))
    else
        DebugPrint("Reset to default value")
    end

VFWUiCenter()

Arguments
none

Return value
